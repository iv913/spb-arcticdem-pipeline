# 5.48. arch.lenobl.ru: потоковый конвейер — 36 544 числовых отметок из векторных PDF

Дата: 2026-09-28. Линия: вторая (main / Super Z).
Контекст: пользователь — «дальше перейди на arch.lenobl.ru». До этого (5.36–5.45):
2+3+3 проекта, 8 архивов, PPT-отметки с плохими координатами (MAD 6.33),
DWG-строки. Здесь — полный обход раздела «Утвержденная документация по
планировке территории» (региональные + муниципальные объекты).

## 1. Конвейер (воспроизводимый, докатываемый)

1. **Разбор сайта**: страница «Утвержденная документация…» отдаёт список
   файлов статически (curl); agent-browser не нужен. Парсер
   (scripts/lenobl_parse_5.48.py) → **103 распоряжения, 458 файлов
   (367 RAR)** — это и есть «442 архива» оценки 5.45.
2. **Группировка**: RAR «Материалы по обоснованию» по распоряжениям;
   дедуп близнецов (суффиксы _XXXXXX), сбор многотомных (part01..partNN).
   Всего 65 групп, 21.14 ГБ.
3. **Потоковая обработка** (scripts/lenobl_pipeline_5.48.py, манифест
   results/lenobl_manifest_5.48.json, докатываемо):
   скачать → распаковать (СТАТИЧЕСКИЙ 7zz 24.08: unrar-free не держит
   RAR5!) → для каждого PDF: PyMuPDF get_text('dict') → числовые токены
   **с цветом** (чёрный = существующий рельеф, красный = проектный —
   правило 5.36 реализовано программно) → в мастер-CSV → удалить.
4. Итог: все 65 групп пройдены (21.1 ГБ скачано и удалено; на диске
   только CSV и манифест).

## 3. Честные ограничения

- Это числовые токены с чертежей/таблиц (векторный текст), НЕ
  выверенные отметки рельефа: в выборку попадают размерные числа и
  пикетаж. Цвет (чёрный) — главный фильтр, диапазон значений шире
  городского (Ленобласть до ~250 м на востоке).
- Координаты отметок — позиции на ЛИСТЕ (доли страницы), не lat/lon.
  Геопривязка — через проекты (названия распоряжений дают район/трассу;
  ПМТ-тексты содержат МСК-координаты — следующий шаг).
- dwg-строки (101-902 значений на проект) — грубые, без позиций.
