# 5.82 — Финальные карты гибрида H2-blend-openoff (обе зоны) + roundtrip tif↔JSON

Дата: 2026-10-06 (сессия IM zai-web, chat c9c249cc). Скрипт:
`hybrid_maps_5.82.py`. Всё из кэшей клипов — без скачиваний. Первые карты
промотированного рецепта 5.80–81 и первые артефакты продукта 2 м в
конвенции M-CLF (Int16, см, БС-77).

## 1. Что сделано

Полная цепочка рецепта (фиксирована, без пере-подбора) на каждой зоне:
фильтр MAD≤1.5 & n≥80 → per-strip offsets по открытым train-точкам
(canopy<1 м; 5.81) → фьюжия p25/p50/σ → blend w=clip((1.5−σ)/1,0,1)
(5.80) → H2 med31(clip(residual,±1)) чанками по 512 строк.

Выход на зону (dem_cache):
- `hybrid_final_2m_5.82_<zone>.tif` — карта, Int16 см, nodata −32768,
  EPSG:4326, PX=0.0000178°, deflate: пилот 17.8 МБ, кросс 16.2 МБ;
- `quality_5.82_<zone>.tif` — 3 канала uint16: n_cov, σ(см),
  канопи30(см) — сырьё для density grid тиража и масок применимости.

Покрытие карт 100% сетки зоны (вне стека residual=0 → продукт = prior).
Диапазон высот пилота/кросса: −1.5…26.0 м БС-77 — физичен (дюны,
Сестрорецк).

## 2. Holdout и roundtrip (пре-регистрация 5.82)

Правило: RT-1 |ΔMAD tif−mem| ≤ 0.01 м и |Δp95| ≤ 0.02 м (квантование см);
RT-2 |ΔMAD tif−5.81| ≤ 0.01 м (детерминизм пере-фьюжии).

| Зона | prior 30м | H2 (mem) | H2 (из tif) | RT-1 | RT-2 vs 5.81 |
|---|---|---|---|---|---|
| Пилот (дюны) | 0.493 / 2.52 | 0.436 / 1.83 | **0.432 / 1.84** | OK (0.004/0.004) | OK (0.436→0.432) |
| Кросс (Сестрорецк) | 0.389 / 2.28 | 0.373 / 1.89 | **0.373 / 1.90** | OK (0.000/0.003) | OK (0.373→0.373) |

- Оба roundtrip-критерия выполнены в обеих зонах; карта в tif и
  in-memory оценка эквивалентны в пределах см-квантования.
- Повторный прогон пилота дал идентичные числа (0.432/1.84) — фьюжия
  детерминирована.
- Датум варианта: resid_off −0.03…−0.031 (было +0.06 у prior; смещение
  открытых ячеек −0.26 в这是我 signage holdout-остатке сохраняется —
  кандидат на глобальную поправку в 5.83+).
