# 5.47. archi.ru: полный конвейер по каталогу 210 проектов — 362 ground-отметки

Дата: 2026-09-28. Линия: вторая (main / Super Z).
Контекст: пользователь — «отработай остальные проекты от начала до конца»,
метод снимания точек — «по перекрёсткам и углам, в основном на открытой
местности (легко позиционировать по карте)». До этого: 71 марка 514913
(MAD 0.46, 5.34/5.46), VLM 198/421 картинок 20 проектов.

## 1. Что сделано (от начала до конца)

1. **Сбор галерей**: через agent-browser (JS-challenge archi.ru проходит
   headless'ом; page_reader больше НЕТ — WAF «Verification») обойдены ВСЕ
   210 проектов каталога (120 из 5.39 + 100 из spb_catalog.csv, дедуп по id,
   33 уже пройденных пропущены). С каждой страницы — title, адрес,
   координаты (блок «информация»), ВСЕ изображения (src/data-src/href →
   полноразмерные id). Артефакт: results/archi_catalog_gallery_5.47.json
   (198 проектов, 3923 уникальных изображения).
2. **Скачивание**: i.archi.ru/i/<id>.<png|jpg> — напрямую, без WAF,
   12 потоков, 2.1 ГБ → wr/archi3/full/ (3926 файлов, 0 отказов).
3. **Локальный OCR-проход** (tesseract rus+eng, PSM 11+6+up2x, токены
   [+N.NN] 0.5–80 м с пиксельными координатами): 3926 изображений →
   972 планоподобных (white>0.45), 277 с токенами.
4. **Классификация VLM пачками по 5** (26 вызовов на 130 кандидатов с
   ≥5 токенами): 96 floor_plan (площади квартир — ЛОЖНЫЕ отметки,
   главный источник шума OCR!), 2 old_map, 16 geoplan, прочее.
5. **VLM-извлечение отметок** с 16 геопланов (value, rel x/y, context,
   kind=ground/structural, улицы). Результат: 180 ground-отметок.
6. **Объединение и расширение 514913**: новый промпт (108) + старый кэш
   (77) + OCR-токены (9 уникальных) → дедуп → фильтр БС-77 5–20 м →
   **156 марок** (было 71).
7. **Геопривязка**:
   - 514913: аффинная rel→lon/lat по 77 соответствиям пира (невязка 0.0 —
     воспроизведение его аффина), санити OSM — в 5.34 было 12.1 м.
   - 456577 (Римского-Корсакова 69): по 2 углам здания (читаны с сеткой)
     ↔ полигон здания OSM (967 м², 10 м от проектной точки): scale
     0.0826 м/px, контроль на 3-м углу 5.8 м. ICP-подход отвергнут
     (маска контура разваливается на эрозии).
   - 422695 (ВО, квартал 2125): «Средний пр» на плане = Наличная ул
     (метка вдоль красной границы); пересечения ОСМ не согласуются с
     пиксельными оценками на ±15–20 м — геопривязка отложена, отданы
     rel-координаты. Урок: якоря по осям улиц требуют точности чтения
     ±5 px, недостижимой «на глаз» через уменьшенные превью.
8. **Валидация**:
   - 514913: |h1-h2| median 0.19 м (1128 пар <30 м) — воспроизвёл
     критерий 5.46 (0.18); dH peer's model MAD 0.308 (centered);

   - 314154 (Октябрьская наб.): 77 ground, |h1-h2| 0.12 м (43 пары) —
     лучшее качество извлечения; медиана 5.96 [4.47–7.83] — физично
     для надпойменной террасы Невы.
   - 456577: 37 ground, |h1-h2| 0.15 м (35 пар), 2.7–4.2 м — бровка
     канала Грибоедова.
   - 257941 (Яхт-клуб, Невская губа): 10 ground, 0.10 м (5 пар),

   - 448114 (Русановская): 43 ground, 0.5–9.9 м — долина р. Утка +

9. **Экспорт**: results/archi_marks_all_5.47.csv — 380 строк

## 2. Главные уроки

- **OCR-токены на поэтажных планах = площади квартир** — до классификации
  VLM их нельзя считать отметками. Локальные эвристики (цвет/слова) не
  отделяют пастельные поэтажные от ч/б геопланов, нужен VLM.
- **agent-browser проходит WAF archi.ru** (page_reader — нет).
- Пиксельные координаты OCR точнее rel-оценок VLM (~±1 % изображения);
  для геопривязки якоря надо читать по сетке на кропах (±10 px ≈ ±5 м
  при 1:500) или сопоставлением контуров.
- GLO-30 через vsicurl — рабочий независимый санити-источник, но в
  городской черте бывают загрязнённые пиксели (+13 м на канале Грибоедова).
