# 5.95b–g — НСПД через RU-прокси: гейт проходим, API-плоскость закрыта (негативный протокол)

Дата: 2026-10-13. Директива: «так используй прокси рф» — обход гео-блока НСПД
публичными RU-прокси после разбора гейта 5.94.

## Постановка

Гейт 5.94 (`nspd_fetch_5.94.py --from-rf`) корректно отказывал вне РФ-сети
(TCP_BLOCK). Гипотеза хода: публичный RU-прокси даст выход к
nspd.gov.ru и позволит фактическую выгрузку КПТ/выкопировок по 7 кварталам
(TARGETS 5.94: Автово, Дачное, Ульянка, Шушары, Колпино, Петергоф,
Сестрорецк). Контекст: валидация юга уже закрыта nakarte-маршрутом 5.95
(5/5 геознаков, MAD 0.06), прокси-маршрут — остаточный независимый контроль.

## Шаг 1 — охота прокси (proxy_hunt_5.95.py)

Источники: proxyscrape (country=RU), geonode API (country=RU), proxifly
(geo-фильтр RU); proxy-list.download — 502. Итог: **334 RU-кандидата**.
Тест: TCP к прокси (5 с) → HTTPS CONNECT к https://nspd.gov.ru/ (TLS
unverified, как в гейте 5.94). 40 потоков.

| Итог | N |
|---|---|
| Живых через гейт (HTTP 200, >800 B) | **4** |
| Слабых (не-200/мало) | 1 |
| Мёртвых | 329 |

Живые: 217.114.12.153:443 (1.7 с), 95.52.246.169:1082 (6.4 с),
62.113.114.246:8443 (9.3 с), 88.204.22.105:8080 (10.4 с).
→ `results/proxy_pool_5.95.json`

## Шаг 2 — гейт через прокси (nspd_proxy_fetch_5.95.py)

`GET https://nspd.gov.ru/` через пул: **HTTP 200, 15 202 B** — доступ к
веб-плоскости подтверждён повторно (гео-блок обойдён). Портал — SPA с
module federation (Vite, 33 бандла в HTML). Запасной маршрут легаси-ПКК
`pkk.rosreestr.ru/api/features/1?bbox=...` по всем 7 TARGETS вернул SPA-
заглушку 12 928 B (HTML index) — **старый PKK API демонтирован**, данных нет.

## Шаг 3 — рекогносцировка API (recon 5.95 d–g)

- Все 33 бандла точки входа — мелкие runtime-чанки (0.2–70 КБ); api-пути
  строятся динамически (`/${e}`), реальных api-строк в них нет.
- remoteEntry федерации на стандартных путях (/map/remoteEntry.js и пр.) —
  SPA-fallback, не модуль.
- `/api/*` uniformly: **403** `{"code":403,"requestId":"...","message":"Forbidden"}`
  — структурный ответ API-шлюза (не nginx). 404 только на несуществующие
  (/api/layers, /api/geoportal/layers).
- Куки-сессии нет (GET / не ставит cookie); /api/auth/*, /api/user — 403.
- Полная браузерная мимикрия (sec-ch-ua, sec-fetch-*, Origin, XRW) +
  прогон через каждый из 4 прокси отдельно: **403 со всех RU-выходов**
  (recon4). api.nspd.gov.ru — не резолвится/не отвечает.

## Вердикт

**Гейт НСПД двухслойный.** Веб-плоскость (CDN-статика) открыта даже через
публичные RU-прокси — гео-блок обойдён. API-плоскость закрыта
репутационно/авторизационно: публичные прокси-IP в запрет-листах шлюза, и
нужна портальная сессия (ЕСИА) — анонимных публичных /api/ нет. Следствие:
фактическая выгрузка КПТ/выкопировок через публичные прокси невозможна;
требуется резидентный РФ-выход + авторизованная сессия, т.е. протокол
5.94 `--from-rf` остаётся единственным легитимным путём сетевой части.

Для плана проекта это **нулевые потери**: валидация датума не-ICESat-2
источником закрыта 5.95 (nakarte, тригопункты 3/3 |dH|≤0.66, MAD 0.06);
отметки НСПД оставались лишь резервным перекрёстным контролем. Пункт 5
§6.5 теперь закрыт тремя протоколами: nakarte-валидация (5.95), протокол
РФ-запуска (5.94) и прокси-протокол (5.95b–g, негативный по API — evidence
вместо прогноза).
