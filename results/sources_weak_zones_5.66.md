## 1. Tier 1 — документальные планировочные источники (высший приоритет)

### 1.1 arch.lenobl.ru — генпланы МО Ленинградской области (этап ③) ✅
- https://arch.lenobl.ru — Комитет градостроительной политики ЛО.
- Раздел «Генеральные планы муниципальных образований»:
  https://arch.lenobl.ru/ru/dokumenty/dokumenty-territorialnogo-planirovaniya/generalnye-plany-municip
- Подосновы генпланов (ПЗу, чертежи) содержат абсолютные отметки по методу
  «перекрёстки/углы/открытая местность» — тот же протокол, что ②.
- Пригоден для приграничных зон СПб: МО вокруг Курортного (Сестрорецкое
  пос., Белоостров), Колпинского (Понтонный, Сапёрный, Металлострой —
  частично ЛО), Пушкинского (Шушары — СПб, Детскосельский — ЛО),
  Петродворцового (Ломоносовский ГО).
- Уже в работе: 36.5k отметок 5.47–5.48 ожидают приёмки/консолидации.

### 1.2 НСПД — nspd.gov.ru (замена Публичной кадастровой карты) ⛔
- Портал пространственных данных Росреестра; заменил ПКК.
- По докладу РФ в UN-GGIM: цифровые топографические планы масштаба 1:2000
  — базовая картографическая основа; КПТ/выкопировки содержат отметки
  высот углов улиц, отмосток и пола 1-го этажа.
- Из внешней сети не отвечает (000) — доступ из РФ / через VPN.
- Использование: выкопировки по кварталам Автово/Дачное/Ульянка,
  Шушары, Колпино, Петергоф, Сестрорецк → отметки в канон ②.

### 1.3 КГА СПб / ИСОГД — kga.gov.ru ⛔
- Документация по планировке территории (ППТ/ПМТ) с чертежами
  вертикальной планировки: красные горизонтали, абсолютные отметки
  проездов, планировочные отметки территорий — идеальный источник для
  «крестов/углов».
- Из внешней сети не отвечает (000); документы дублируются на
  gov.spb.ru и сайтах «активных граждан» при обсуждениях.
- Дополнительно: сводный реестр ППТ в «Настольной книге девелопера»
  (kachkin.ru, 2024) — указатель к первоисточникам.

## 2. Tier 2 — глобальные DEM (бесплатные, для кросс-проверки и заполнения пробелов)

| Продукт | Тип | Разрешение | Доступность | Роль в слабых зонах |
|---|---|---|---|---|
| Copernicus GLO-30 | DSM | 30 м | ✅ (OpenTopography; в пайплайне) | базовая кросс-проверка; MAE ~0.87 м на плоском рельефе (лит. оценка) |
| FABDEM V1.2 | DTM (убраны лес/здания) | 30 м | ✅ data.bris (главная); fabdem.com из сети 000 | **целевой** для прибрежных плоских зон — bare-earth, прямая сопоставимость с отметками земли |
| DeltaDTM (4TU) | DTM coastal | 30 м | ✅ data.4tu.nl (200) | прибрежные зоны: Кронштадт, Курортный, Петродворцовый, юг Финского залива |
| GEDTM30 (OpenLandMap) | DTM (ensemble, обучен на ICESat-2+GEDI) | 30 м | ✅ stac.ecodatacube.eu (200) | независимая третья оценка для консенсуса |
| AW3D30 (JAXA) | DSM | 30 м | ✅ portal.opentopography.org (200) | четвёртый член консенсуса; известных смещений в воде избегать |
| ALOS PALSAR / AVDM | RTC/DSM | 12.5 м | ✅ daacdata.apps.nsidc.org (200) | РЛС-запасная оценка; шум в городской застройке |

Замечания:
- GLO-30/LE90 < 4 м глобально, но на плоской территории СПб литературные
  оценки MAE ~0.87 м — приемлемо для грубой валидации зон, не точек.
- FABDEM/DeltaDTM/GEDTM30 — консенсусное среднее трёх bare-earth DTM
  снижает случайный шум ~√3; смещения каждой модели известны из литературы.
- Все модели — WGS84 эллипсоид; пересчёт в БС-77 обязательен (уже сделан
  в пайплайне для GLO-30; использовать ту же процедуру geoid-коррекции).

## 3. Tier 3 — космическая альтиметрия (точечные, метровые)

### 3.1 ICESat-2 ATL08 ✅
- https://nsidc.org/data/atl08 (200); STAC-зеркало: stac.openlandmap.org.
- По земле точность 0.1–0.3 м; в текущем наборе только 11 точек per-RGT.
- Расширение: все ATL08 ground-фотонные классы ( ATL08 land_photons,
  class 2) в пределах слабых зон за 2018–2026; фильтр open terrain
  (перекрёстки/поля — та же логика «открытой местности»).
- Ограничение: треки редкие (0.7–3 км между соседними), облачность;
  для Кировского/Красносельского/Колпинского за 8 лет — десятки точек,
  для Кронштадта/Котлина — единицы (уже проверено в 5.52 — 11 RGT).

## 4. Tier 4 — архивно-фондовые и краудсорс

### 4.1 Росгеолфонд / техотчёты изысканий ✅
- https://reports.geologyscience.ru (200) — реестр отчётов (ИГИ).
- Техотчёты инженерно-геодезических изысканий содержат планы
  топографической основы 1:500–1:2000 с отметками — тот же метод ②.
- Также: наш.дом.рф — карточки проектов публикуют техотчёты ИГДИ
  (корень 403 из внешней сети, PDF по карточкам доступны);
  lk.iaoo.ru — образец регионального фонда-портала ИГИ.

### 4.2 Исторические съёмки с горизонталями
- geokniga.org ✅ — геодезическая библиотека: геологические листы с
  горизонталями (о. Котлин — лист O-35-36N), каталоги высот
  нивелирной сети (в т.ч. «Каталог высот русской нивеллирной сети
  1871–1893» — марки КВТ на фасадах).
- Генштаб 1:10000/1:25000 на пригороды (Пушкин, Колпино, Петергоф,
  Сестрорецк, Зеленогорск) — горизонтали с сечением 2.5–5 м; этоместо
  (etomesto.ru) из внешней сети 000, проверять из РФ.
- Использование: только для рельефной структуры зон (косвенная
  валидация полей), не для точечных отметок (устаревание застройки).

### 4.3 Стенные нивелирные марки (краудсорс)
- Фото-каталоги марок/реперов (LiveJournal: «ГРИИ», корпус военных
  топографов; современная ГГС) — дают адресный список точек с высотами
  из каталогов; современные каталоги высот марок/реперов I–II классов
  получаются через НСПД/Росреестр по запросу.
- Роль: контрольные точки-якоря для геопривязки планов (метод ②),
  а не валидационный массив.
