# Гибридный 2м DEM Санкт-Петербурга — финальный сводный отчёт (5.66–5.95)

Дата: 2026-10-13. GitHub: iv913/spb-arcticdem-pipeline (коммиты 7708681, c240c21).
PDF-версия: download/spb_dem_final_report_5.66-5.95.pdf (11 стр.).

## 1. Резюме

Проект построил городской 2м DEM Санкт-Петербурга в БС-77 из открытых
стерео-данных с калибровкой по ICESat-2 ATL06 и пер-пиксельным гейтом
доверия. Путь: от owner-map Большого пр. В.О. (5.1) до валидированного
городского продукта (5.95). План источников 5.66 §6.5 исчерпан; п.5
(НСПД/КГА) закрыт тремя протоколами.

- Канон v4: 375 751 base + 141 157 DSM, 56 225 ячеек 0.001°; MAD
  high-base 0.309 / med-base 0.327 м.
- Мозаика 5.90: 84 зоны, Int16 см БС-77; юг — 4 района, 244.9k точек.
- Гейт M-CLF-v3: gold 305.4M / ok 68.3M / rest 274.9M / excl 988.5M px;
  политика ok+gold; MAD gold юга 0.226–0.296.
- Независимая валидация (5.95, nakarte): 5/5 геознаков |dH|≤0.66 м,
  MAD тригопунктов 0.06 — датум БС-77 подтверждён не-ICESat источником.
- Пакет поставки: 6 продуктов, ≈933.7 МБ, sha256 в манифесте.

## 2. Датум и конвенции

БС-77, дельта +16.04 м (§6); dH2m = h_baltic − dem2m; растры в Int16 см
(dem2m = sample/100); ND: −32768 (DEM), 65000 (quality), 255 (маска);
сезонное правило 11–04 = leaf_off; паритет-сетка 0.02°×0.0127°, дедуп
0.001°.

## 4. Гибридная мозаика 5.90

Рецепт тиража (заморожен в 5.82): leaf-off STAC → open-offsets (canopy<1м)
→ MAD-фильтр → blend w=clip((1.5−σ)/1,0,1) → H2 med31(clip±1). Правило:
prior train MAD ≥ 0.45 → гибрид, иначе prior; стек отбракован. 7 зон
(5.76–5.79) + 14 (5.83) = 21 (мозаика 5.84: MAD 0.197, смещение 0); юг
(5.90) добавил 4 района/244.9k; итог — 84 зоны, продукты mosaic/quality/
trust_mask.

## 5. Гейт доверия M-CLF-v3

## 6. Независимая валидация 5.95 (nakarte)

scrape_topo_5.95.py: 20 ячеек (слои ГШ AtloMaps), кадры с px-привязкой
±50 м; транскрипция оператором (VLM rate-limit): 11 отметок. Валидация:
2 604 → 291 ячейка (дедуп 0.001°), 141 в footprint / 141 вне (DXF Дачное
2 216 тчк), триаж |dH|≥15 — 9. Тригопункты 3/3: Колпино −0.12 (gold),
Дудергоф +0.55, Александровка +0.49, MAD 0.06; урезы 2/2 (−0.45, −0.66).
otmetki med −0.43 / MAD 0.91 — систематика планировки +0.4; пилот 5.44
отбракован (grid-center 300–500 м); км-сетка отбракована триажем.
Протокол воспроизводим: scrape → transcribe → validate. График:
results/chart_mad_south_final.png.

## 9. Хронология стадий

5.1 owner-map В.О. (видимость/вода/CRS) → 5.2 road reconstruct (MAD
0.71→0.13) → 5.2-cal «кроссворд» 63 точки (bias +2.58, shift 18.475) →
5.14 глобальный уклон 0.67 м/км → 5.15 аудит (|dH|—дистанция +0.284;
сигнал<шума) → 5.24 независимое воспроизведение → 5.44–5.49 topo-пилот +
lenobl метод ② → 5.65–5.66 анкоры и план → 5.68–5.70 негативы →
5.71–5.73 consensus/site test/archi-fabdem → 5.74–5.75 стрипы (473 пары) →
5.76–5.79 семь зон тиража → 5.80–5.82 hybrid final/maps + recovery →
5.83 батч (+14 зон) → 5.84 мозаика 21 (MAD 0.197) → 5.86–5.87 «глазами» +
сезонная диагностика (33.9→129.8k) → 5.88 канон v2 → 5.89 M-CLF-v3 +
дамп 255k → 5.90 юг + мозаика 84 зоны → 5.91 гейт v3 (346 755) →
5.92 can30-патч → 5.93 уплотнение (канон v4) → 5.94 НСПД/КГА (аудит,
протокол, пакет) → 5.95 nakarte (5/5, MAD 0.06) + прокси-негатив (API 403).

## 10. Ограничения и следующие шаги

Ограничения: rest-полоса леса (can30 50–200) не поставляется (кэп 0.45);
MAD base 0.309–0.327 — физика стерео в застройке; систематика планировки
+0.4 м — свойство отметок; НСПД требует ЕСИА+резидентный РФ; OSS/Drive —
нет кред; отложены DXF Дачное и OK(S)-лес.
