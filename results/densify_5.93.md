# 5.93 — Уплотнение съёмки ATL06 (HIGH + MEDIUM)

Дата: 2026-10-13. Статус: **закрыт, решение GO по cnf=3 (MEDIUM)**.

## 1. Задача

«Уплотнение съёмки ATL06 (больше точек) на юге и в лесных зонах» — пункт Next
блока 5.92. Канон v3 (333,788 base) построен только на HIGH-сегментах
(5.86e/5.89b: cnf=4). Вопрос этапа: даёт ли смягчение cnf прирост валидационных
точек приемлемого качества, и как его включить в канон без перекалибровки
гейтов.

Протокол дампa заморожен, меняется ровно один параметр: cnf HIGH(4) →
MEDIUM(3) / LOW(2) (ATL03 signal_conf_ph: 4=high, 3=medium, 2=low; фильтр
«≥ порога»). Остальное: len=40, res=20, ats=10, cnt=5, maxi=1, srt=LAND,
2019-01…2026-12, δ=16.04 (БС). Окна детерминированы len/res → дедуп по ключу
(rgt, cycle, gt, date, round(lat,4), round(lon,4)); северный дамп 5.86 без
time_ns, поэтому ключ координатный (шаг окон 20 м > ячейки 11 м — коллизий
нет); контроль на южном тайле: ложные «новые» 2/5,513 и 0/12,435 (≤0.04%).

концентрируются в prior-ветви (юг + prior-only зоны севера), качество на юге
0.251 — не хуже HIGH-юга (0.309 в 5.91).

## 5. Валидация

MAD (м) по источникам (base, все точки): high 0.309 (n=335,791) / med 0.327
(n=39,960) / **med в новых ячейках 0.328** (n=16,380) — цена уплотнения
+0.018 MAD. Gold: high 0.273 / med 0.290. Leaf-off: high 0.312 / **med 0.232**
(n=7,006) — зимние medium-точки не хуже. Cell-median MAD 0.321 (56,225 ячеек)
— коридоры не искажают.

Holdout по тирам (замороженные пороги):

Пушкинский 0.226, Колпинский 0.296 (5.91: 0.240/0.309/0.241/0.317 —

Зоны (84, маски с перекрытием по конвенции 5.83): med-точки появились во всех

## 6. Выводы и решения

1. **Канон v4 = 375,751 base + 141,157 dsm, 56,225 ячеек** — строго богаче v3
   при деградации MAD ≤0.02; med-точки несут флаг cnf_src="med" и могут быть
   отфильтрованы без пересборки.
2. Гейты M-CLF-v3 не перекалибровывались: замороженные пороги 5.91/5.92 сами
   фильтруют шумные medium-окна (в strip-зонах проходит <2% новых окон).
3. cnf=2 (LOW) отбракован навсегда (gold 0.50–0.67 по всем тайлам).
4. Уплотнение закрыло главную дыру выборки — prior-ветвь (юг + N1/N13/AVTOV/
   LIGO): +41% med-base точек в новых ячейках; leaf-off база расширилась
   (med 7,006 точек, MAD 0.232).
5. Дальше по плану: НСПД/КГА.
