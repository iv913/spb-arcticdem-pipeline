# 314154 — адресные якоря пользователя (86 к2 + общежитие 88/2) и пере-проверка 5.65

## Постановка
План 314154 (i.archi.ru/i/314154.jpg, 2500×1666, 43 отметки 4.23–6.60 м по OCR 5.47,
88 отметок по VLM 5.47-серии) получил 5.53 статус «не геопривязываем» (7 сценариев
регистрации, cost 4.8–12.5 м). В 5.53 протоколе записано: «кандидат-адрес для
повторной попытки (если пользователь подтвердит)». Пользователь подтвердил и расширил
якорную информацию двумя адресами:

1. **Октябрьская наб., 86, корп. 2** — адрес проекта на archi.ru
   («Жилой дом на Октябрьской набережной», «дом 86, корпус 2, литер А»).
2. **Октябрьская наб., дом 88/2** — адрес бывшего общежития при ТЭЦ-5; на плане
   подписано «4К общежитие ТЭЦ-5» (южный контекстный корпус за границей участка).

Оба объекта разделяют геопривязку плана 314154. Настоящий протокол фиксирует эти
два пункта как якорные данные набора отметок.

## Геокодирование и верификация (5.65)
- «Октябрьская набережная 88» — многокорпусный комплекс: к1 (59.871545, 30.470187),
  **к2 (59.871893, 30.469894)**, к3 (59.872182, 30.470743), к4 (59.872792, 30.470974),
  к5 (59.873334, 30.470593), к6 (59.873587, 30.471152). Т.о. «88/2» = дом 88,
  корпус 2 — 60–130 м к В-ЮВ от точки 86 к2 (59.8723521, 30.4691565, REF 5.53).
- Полигон корпуса 88 к2 по Nominatim: wx=[19..63], wy=[-63..-40] м в системе REF;
  фактическое здание по карте OSM смещено к (42..87, -61..-75) — полигоны
  Nominatim для корпусов грубые (5–6 вершин), смещение до ~20–25 м. Для метровой
  привязки не годятся, только как поисковые затравки.
- Этажность: «4К» на плане = «4-этажный корпус»; OSM для здания 88 к2 даёт
  «2-4» этажа — согласуется. Комплекс 88 к1…к6 — сохранившиеся ведомственные
  дома ТЭЦ-5 (правобережная ТЭЦ-5 «Уткина Заводь», 59.8725, 30.5032).
- Снимок Esri z17/z18 (59.8680–59.8765, 30.4620–30.4830): квартал малоэтажный,
  **башен проекта нет** — вывод 5.53 «к1/к2/к3 = построенные ЖК-башни» ОШИБОЧЕН
  (это адресные полигоны/узла точек, не башни). Здание 86 к2 (комплекс с Ozon-ПВЗ,
  OSM «171:220») — существующий комплекс иной морфологии, чем проектируемые
  корпуса плана; интерпретация «план реализован как Сосновка» не подтверждается.
- Регистрация с якорем «общежитие→88 к2» (5.65): скан масштабов 0.08–0.32 при
  θ = −10…+10° (север-вверх, якорная трансляция), ICP по корпусам, оверлеи —
  устойчивого решения НЕТ: (а) стены плана загрязнены дорогами/текстом;
  (б) противоречие масштабов «общежитие 470 px ↔ 45 м» (s≈0.10) против
  «кольцо участка 1335 px ↔ квартал 143 м» (s≈0.11) против глобального скана
  (s≈0.175, cost 3.29 — не подтверждён визуально); (в) полигоны корпусов
  смещены. Промбаза плана снесена (5.53), существующий контекст квартала
  перестроен — статус «не геопривязываем по текущим снимкам» ПОДТВЕРЖДЁН.

## Что это меняет для набора отметок
- Участок плана ПОДТВЕРЖДЁН пользователем: квартал домов 86–88 по Октябрьской
  наб. (Сосновка, Невский р-н). Сайтовая атрибуция 88 отметок VLM (в
  archi_final_expanded_v2.csv, сайт-центроид 59.8737032, 30.4608983) —
  КОРРЕКТНА, отметки остаются в наборе (сайт-уровень).
- Построчная (per-mark) геопривязка остаётся невозможной — план исключён из
  per-mark набора (решение 5.53 не пересматривается).
- Валидное знание по высотам: отметки 4.23–6.60 м (OCR, conf≥90: 28 шт) на
  участке у Набережной; h_model на сайте 1.97 м → dH ≈ +3.5…+4.6 м — согласуется
  с систематикой 5.58 (модель занижает на востоке города, dH=+3.99 м по
  сайту 314154).
