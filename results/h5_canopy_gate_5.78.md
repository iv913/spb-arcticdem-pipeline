# 5.78 — H5 (гейт residual по канопи): НЕ промотирован; гибрид 2м остаётся zone-специфичным

Дата: 2026-10-06 (сессия IM zai-web, chat c9c249cc). Скрипты:
`h5_canopy_gate_5.78.py` (+ портация HOME в скриптах 5.76: автодетект
корня репо от `__file__`). Пилот 5.75/5.76 восстановлен из STAC с точной
репликацией (holdout p25 0.491/5.53 — совпадение до третьего знака).

## 1. Пре-регистрация (из диагностики 5.77)

corr(|residual|, канопи)=0.395 vs corr(|residual|, sigma)=0.057 → гипотеза:
гейт по канопи g_can=exp(-(canopy/σc)²) должен работать там, где sigma-гейт
слеп (системный leaf-on bias). Кандидаты: H5a (канопи-гейт, σc∈{0.5,1,2}),
H5b (канопи+sigma). Отбор ТОЛЬКО на train пилота, score=MAD+0.25·p95;
валидация: holdout пилота + кросс-зоны («Сестрорецк-запад»); промоция —
MAD≤H0 И p95≤H0 в ОБЕИХ зонах (правило 5.77 усилено).

варианты H5 проигрывают протокольному clip1.

снова holdout-лидер пилота — его «победа» 5.76 не воспроизводится отбором
и не переносится между зонами; надёжным признаётся только H2.

## 4. Итоговая интерпретация трёх блоков (5.76→5.78)

1. **Гибрид 2м — не универсальный рецепт, а режим применения.** Ценность
   2м-стека реализуется при (а) плотном стеке, (б) leaf-off сценах,
   (в) открытом рельефе (дюны/валы/намыв). В лесо-городской зоне 30м-приор
   устойчивее на MAD, выигрывает по всем точкам канопи-разреза.
2. **Гейты не спасают**: sigma-гейт слеп к системному bias кроны (5.77),
   канопи-гейт режет полезный сигнал дюн (5.78). Причина общая: residual
   гетерогенен по природе (деталь рельефа ↔ bias кроны ↔ смещение кромки
   воды), а гейты скалярны.
3. **Правильная архитектура финального продукта — композит**: prior 30м
   везде + 2м-деталь ТОЛЬКО в ячейках, где (n_cov≥6) ∧ (σc≤1 м) ∧
   (канопи<1 м) ∧ leaf-off-флаг стека. Маска применимости — вместо гейта
   значения. Это и есть задача тиража 5.79.
4. Честная фиксация: «2м-карта с качеством 30м» (5.76) верна для дюнного
   пояса; для всего ареала корректнее «30м-карта с 2м-деталями там, где
   стек чист».
