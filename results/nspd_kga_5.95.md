# 5.95 — Выкопировки: независимая валидация отметками высот (БС-77)

Дата: 2026-10-13. Основание: выбор пользователя («5.95-выкопировки») после
закрытия 5.94. Скрипты: `scripts/scrape_topo_5.95.py`,
`scripts/validate_marks_5.95.py`, данные `scripts/marks_new_5.95.json`.

## 1. Гейт НСПД и выбор пути

Повторная проба `nspd_fetch_5.94.py --from-rf` (2026-10-13): nspd.gov.ru →
TCP_BLOCK — сеть РФ по-прежнему недоступна из среды. Выкопировки выполнены
единственным доступным документальным путём: слой «Soviet topo maps
(AtloMaps)» на nakarte.me (HTTP 200 из этой сети) — отсканированные
советские топокарты в БС-77 с уже готовой веб-геопривязкой (нет «проблемы
якоря», погубившей lenobl-пакет в 5.70).

## 2. Метод 5.95 (в отличие от пилота 5.44-эры)

- сетка 20 ячеек 0.05° по периферии footprint мозаики 5.90 (запад/Петергоф,
  Курортный, Колпино-Пушкин, юг, город; город дублирует otmetki);
  z=15, viewport 1600×900, кроп карты без UI 1005×835 px;
- отметки распознаны по кадрам оператором (VLM упирался в rate-limit 429):
  значение + px-центр подписи/знака; px → WGS84 через Mercator-математику
  вида (точность позиционирования ~±20 px ≈ ±50 м);
- типы: spot (тригопункты/отметки), urez (урезы воды), contour (подписи
  горизонталей); лесные формулы «17/0,23» и характеристики дорог
  («30-14/60», «35-8») отбрасывались при транскрипции;
- QC/триаж: дедуп 0.001°, z∈[0;80] БС-77, |dH|≥15 → отбраковка;
- валидация: dem2m = sample(мозаика 5.90)/100 (конвенция 5.90/5.91,
  round, ND=−32768), класс гейта — из mclf_v3_mask_5.90.tif.

## 5. Вердикт

1. **Датум БС-77 мозаики 5.90 независимо подтверждён** геодезическими
   знаками (тригопункты + урезы): 5/5, |dH| ≤ 0.66 м, MAD тригопунктов
   0.06 м. Впервые в проекте валидация не-ICESat-2 источником с px-точной
   привязкой.
2. Полевые otmetki подтвердили известную систематику «отметка планировки
   выше земли» (+0.4), не противоречат мозаике.
3. Старый пилот ГШ-отметок (5.44-эра) непригоден для 2-м валидации из-за
   позиционной ошибки; метод 5.95 (px-привязка) заменяет его.
4. Сеть РФ остаётся единственным путём для НСПД/КГА-выкопировок КПТ/ППТ
   (протокол 5.94 готов); ГШ-слой nakarte — доступная замена для
   независимого контроля датума.
