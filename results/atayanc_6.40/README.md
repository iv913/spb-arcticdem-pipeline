# 6.40 — Полный реестр высотных отметок плана Атаянц (SR-апскейл)

## Что сделано
Задача: «через модель апскейла повысить четкость высотных цифр и глазами найти все
высотные точки, их там гораздо больше». В 6.30 вручную было прочитано только **50**
отметок (Tesseract на курсивных цифрах не работает, 0/564).

### SR-апскейл (модели, не интерполяция)
- **EDSR x4** (OpenCV dnn_superres, `models/EDSR_x4.pb`) — детальные кропы каждой
  отметки: цифры увеличиваются с ~10 px до ~40 px, читаются уверенно.
- **LapSRN x4** — 25 тайлов всего листа (2496×1792 → рендер 1568 px ≈ 2.5x к нативу)
  для сплошного визуального скана.
- Контактные листы: `sheets_edsr/edsr_00..09.png` (596 кандидатов детектора),
  `recheck_00..03` (52 неоднозначных, кроп с маржой 15 px), `cluster_00..06`
  (разбор кластеров), `zone_*.png` + `zonecrop_00..04` (релакс-детекция в плотных
  зонах), `viscrop_00..09` (верификация 551 визуальных точек).

### Двухконтурный поиск
1. **Детекторный контур**: связные тёмные глифы (4–18 px) → строки (3–9 глифов) →
   596 кандидатов → прочитано вручную по EDSR-листам → 81 отметка (включая кластер
   колодцев 2.27/2.71/3.08/3.18 и репер «2.32 репер» у стадиона).
2. **Визуальный контур** («глазами»): сплошной скан 25 тайлов с оверлеем найденного
   (`tiles_overlay/`) → 551 новая точка → EDSR-верификация → принято 366, брак 185
   (этажности «ЭКН», коды коммуникаций «6.тр 1282», координатные подписи, слипшиеся
   глифы).

### Итог
- **377 отметок** после дедупликации (<18 px), против 50 в 6.30 — рост в 7.5 раза.
- Уверенность: H — 10, M — 198, L — 169 (`conf` в CSV; L = цифры частично
  корректны, требует контроля).
- Диапазон 0.17–6.85 м БС-77; плотные зоны: Дворцовая пл. (кольцо 2.8–3.0),
  Стрелка/Биржа (1.4–2.0), Университетская наб., Мойка/Юсуповский, стадион
  им. Ленина (СЗ-фрагмент, 22 отметки).

### Геопривязка и валидация
- Основной аффин 6.30 (`georef_6.30.json`, RMS ~20 м); для СЗ-фрагмента — локальный
  аффин `nw_affine_6.30.json` (флаг `nw_fragment=1`).
- Валидация vs DSM 6.30 (1 м, **сантиметры!**): медиана diff −1.57 м, 75% перц.
  −0.09 м. Хвост |diff|>3 м (143 шт.) — попадание сэмпла в крыши DSM (это DSM
  поверхности, не DTM) при ошибке аффина ~20 м, а не ошибки чтения цифр. Колонки
  `dsm630_m`, `diff_m` — диагностические.
- Стыковка с 50 отметками 6.30: 39/50 покрыты каталогом (рад. 35 м с учётом RMS
  аффина), 18 значений совпали точно; остальные перечитаны заново на 4x-кропах —
  ряд значений 6.30 уточнён.

## Файлы
- `marks_catalog_6.40.csv` — полный реестр (id, px, py, h_bs77, conf, src, nw, lon/lat, dsm630, diff).
- `plan_marks_6.40.geojson` — то же в WGS84 (397 точек, свойства id/h_bs77/conf/src/px/…).
- `overview_marks_6.40.png` — план с нанесёнными всеми отметками (цвет = уверенность).
- `candidates_6.40.json`, `zones_6.40.json`, `clusters_6.40.json`, `vis_spots_6.40.json`,
  `marks_px_6.40.json` — промежуточные данные конвейера.
- `sheets_edsr/` — все контактные листы чтения (42 МБ, доказательная база).
- `tiles_lapsrn/`, `tiles_overlay/` — SR-тайлы и оверлеи скана (238 МБ, в git не входят).

## Скрипты
`scripts/atayanc_6.40a_sr_sheets.py` (детектор+EDSR+LapSRN) → `6.40b_recheck.py` →
`6.40c_clusters.py` → `6.40d_zones.py` (релакс-детекция зон) → `6.40e_zonecrops.py` →
`6.40f_overlay.py` (оверлей на тайлы) → `6.40g_tiles.py` → `6.40h_viscrops.py`
(551 точка скана → кропы) → `6.40i_catalog.py` (слияние, дедуп, геореф, CSV/GeoJSON).

## Использование
Отметки — готовые высотные якоря БС-77 для сшивки 5.97 (ярус «gold»-подобных
точечных данных в центре города) и для калибровки локальной DSM 6.30. Для дальнейшей
автоматизации: Tesseract по-прежнему не читает курсив, но связка «детектор глифов +
EDSR x4 + ручное чтение контакт-листов» воспроизводима и расширяема на следующие
листы плана (atayanc-2013-02…, если появятся).
