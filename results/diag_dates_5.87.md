# 5.87 — Дата-коррелированная диагностика «модель ↔ ICESat-2» (триплет оптики)

Дата: 2026-10-09. Скрипты: `scripts/diag_dates_5.87.py` (листы),
`scripts/seasonal_filter_5.87b.py` (сезонный разрез демпа).
Листы: `download/diag_5.87/ice_*_dates.png` (10 шт).
Данные: `results/diag_dates_5.87.json`, `results/seasonal_filter_5.87.json`.

## 1. Постановка (запрос)

Для худших кластеров расхождений «модель 5.84 ↔ снятые точки» соотнести три
даты: (а) дата данных, из которых собрана модель в этой точке (дата стрипа
ArcticDEM для гибридных зон; эпоха приора GLO-30/FABDEM ~2011–2021 для
prior-зон), (б) дата съёмки ICESat-2, (в) текущее состояние. По паре
оптических снимков «на дату модели» и «на дату ICESat» понять, что видит
модель, что было на точке в момент лазерной съёмки и почему отметки не
совпали; затем — правило фильтрации для «снятия большего количества точек»
(демп 5.86e: 691,818 сегментов → 289,828 покрытых мозаикой → 123,957 новых
сверх канона 5.70).

## 2. Метод

- Кластеры: топ-10 `icesat_worst` из `worst_points_5.86.json` (sev 1.53→0.9),
  дедуп центров <300 м → 10 листов.
- Даты ICESat: демп 5.86e (`scripts/dem_cache/atl06_tiles/*.csv`, поле
  `time_ns`), h_baltic = h_mean − 16.04; dH = ice − модель.
- Даты стрипов: PGC STAC `arcticdem-strips-s2s041-2m` по bbox кластера;
  правило рецепта 5.80–81: leaf-off (Nov–Apr), cloud ≤ 20 %, valid ≥ 50 %
  (значения PGC — доли 0–1, нормированы).
- Оптика: Sentinel-2 L2A TCI (Earth Search, 10 м) — панель A (дата модели),
  панель B (дата худшей экспозиции ICESat = дата с максимальным |med dH|);
  ESRI World Imagery (Vivid, ~0.3 м) + identify — панель C (текущее);
  hillshade мозаики 5.84 + dH-точки — панель D.

## 4. Диагноз: почему «модель ≠ точка»

1. **Все 10 худших экспозиций — leaf-on (июнь–сентябрь).** В leaf-off
   экспозициях тех же кластеров медианы близки к нулю
   (например, 60.0085_30.4311: 2020-03-14 +0.0, 2022-03-10 +0.6,
   2024-03-06 +0.3 против 2025-09-02 **+4.1**). Модель в этих точках
   корректна; ломается летняя съёмка.
2. **Лесные кластеры (RZHEV, N7; канопи 119–221 см).** Модель = земля
   (leaf-off стрипы / prior), ICESat летом ложится на кроны → систематический
   плюс +2…+4 м, растущий с высотой канопи. Это валидация DSM, не DTM.
3. **Городские кластеры (LIGO, N6, N1; канопи 0).** Худшие экспозиции
   2020-06-12 / 2025-09-02 дают +5.2…+7.0 м — засветка крыш низких кварталов
   в 40-м сегменте (коломенская застройка, каналы); зимой/весной тот же
   пиксель даёт 0…+1.7 м. Дополнительно возможны реальные изменения
   (стройка 2020 г. поверх эпохи приора) — лист C показывает текущее
   состояние для проверки.
4. **Растянутый во времени разрыв «стрип → ICESat»** в гибридных зонах:
   поверхность модели 2022-03-05/08, худшие экспозиции 2025-09-02 —
   1277 дней; при канопи ≥ 1 м это гарантирует несоответствие фенологии.
5. **Смещение датума не подтверждено**: ни один кластер не показал
   однородного сдвига с MAD < 0.35 — все отказы объяснимы фенологией/крышами.

по протоколу 5.68-C обязательна; (г) итоговый «золотой» контур:
\|dH\|≤3 + канопи<1 м → MAD 0.32, p95 1.52, 80.7k точек (leaf-off) /
~208k (оба сезона).

## 6. Правило фильтрации для интеграции новых точек (5.88)

1. Основной контур DTM-валидации: `|dH| ≤ 3.0` (5.68-C) **и** `canopy30 < 100 см`
   — сезон НЕ ограничиваем (в открытом городе leaf-on не хуже).
2. Кроны (canopy30 ≥ 1 м) — отдельный бакет DSM-контроля; в DTM-канон не
   включать. При необходимости использовать только leaf-off с поправкой
   на med +0.70.
3. Зимние хвосты: обрезка |dH|≤3 (уже в правиле 1); дополнительно отбраковать
   сегменты по воде/снегу через существующий trust-маску и sigma.
4. Канон 5.70 (33,908) → ожидаемо ~150–210k валидных точек; MAD контура
   ~0.32–0.35 (у листа 5.86: 0.181 на старом каноне с trust-фильтром).
