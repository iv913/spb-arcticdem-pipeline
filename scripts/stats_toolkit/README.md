## Правила, зашитые в toolkit (§1 handoff)

1. Вердикт никогда по точечному MAD — только парные тесты
   (`paired_verdict`): значимость = число сработавших из {знаковый,
   Уилкоксон, CI медианы не содержит 0}; 0 → NOT_SIGNIFICANT,
   1 → MARGINAL, ≥2 → SIGNIFICANT.
2. ICESat — только треками: `n_eff` = число RGT («~10–12, not 37K»),
   точки одного трека схлопываются медианой.
3. Порог практической значимости 0.1 м — отдельное поле
   `practically_significant`, никогда не смешивается с p-значениями.
4. Подача `rgt` обязателен для ICESat; расчёт по точкам существует только
   как контрпример `paired_verdict_per_point_wrong`
   (флаг `per_point_bootstrap_wrong`, имя из ревизии 5.67).

## Инфляция p-значений по точкам (пункт E)

Измерено на контрпримере в ревизии 5.67 (`icesat_per_rgt_retest.json`):
тот же набор точек, CI по точкам шириной **0.011 м** против CI по RGT
**0.238 м** — занижение неопределённости в **21 раз**; p по точкам
(p = 9×10⁻⁴⁶ в `part_2_icesat_near_tagged`) на три–шесть порядков ниже
честных по трекам (p = 0.109 знаковый, 0.064 Уилкоксон). Механизм: точки
одного трека коррелированы (40-м сегменты, один проход), эффективная
выборка — треки, а не точки; любая значимость, посчитанная по точкам,
недействительна. `ci_shrink_factor(diffs, rgt)` печатает фактор для
любого нового набора — включать в отчёты рядом с вердиктом.

Зависимость: numpy; scipy опциональна (обе ветки теста согласованы).
