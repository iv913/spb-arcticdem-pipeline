# Проверка привязки листа «Атаянс-2013» по зданиям OSM

Независимо от GCP агента: контуры зданий листа (цветовая маска) сопоставляются
с полигонами OSM (`results/atayanc_6.30/plan_buildings_6.30.geojson`) по всему
листу и по 12 тайлам (ECC, аффинное). Затем отметки каталога 6.50 (по точке,
`px_bullet`) пересчитываются потайловой привязкой и проверяются без высот
(в воде / внутри зданий) и по высотам (поверхность 6.00 − отметка).

```bash
python3 1_register_sheet.py atayanc-2013-01.jpg $REPO georef.npz
python3 2_replace_marks.py  atayanc-2013-01.jpg $REPO georef.npz spb_terra_fusion_6.00_A2.tif marks_regeoref.csv
```

Результат 02.11 (лист 2576×1821): 9 из 12 тайлов — сдвиг 0.3–4.8 м против привязки
агента; верхняя полоса 4–9 м; отметки сдвигаются на медиану 1.5 м; dH +1.00 → +1.00 м.
СЗ-фрагмент этим скриптом не перепривязывается (у агента своя аффинная).
