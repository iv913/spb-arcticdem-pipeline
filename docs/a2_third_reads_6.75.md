# 6.75/A2 (часть 1) — третьи чтения 94 конфликтов Атаянс: пул v3

**Метод (слепота):** для каждой из 94 точек `use=third_read` вырезан кроп
220×160 px вокруг точки из исходного листа (atayanc-2013-01.jpg), upscale ×4,
тонкое красное кольцо r=3 в точке. Прежние значения (`h_claude`, `h_agent`)
в промпт не попадают; чтение выполняет отдельная VLM-модель через
`z-ai vision` (скрипты `a2_blind_read_6.75.py` — нарезка/чтение,
`a2_resolve_6.75.py` — сверка). Контакт-листы 6.73 не используются напрямую —
кропы режутся из исходника (без подписей ID в кадре).

**Калибровка читателя (пилот на 15 confirmed, где истина = два совпавших
прежних чтения):** точных совпадений 8/15 (53%). Типовые ошибки — первая
цифра (3→1, 4→2) на бледной печати. Отсюда консервативное правило принятия:
подтверждение только при согласии VLM с одним из прежних чтений.

## Правила и исходы (94 конфликта)

| вердикт | правило | n | вес/статус |
|---|---|---|---|
| resolved_2of3 | VLM == claude или agent (≤5 мм) | **36** | в землю, w=1.0 |
| resolved_2of3_near | VLM в 0.10 от claude/agent | **14** | в землю, w=0.9 |
| unresolved_3diff | три чтения расходятся | **43** | вне земли (сохранены) |
| unresolved_no_read | файл чтения отсутствует | 1 | вне земли |

Кто «победил» при разрешении: claude 32, agent 18 — без выраженного
перевеса, конфликтующие чтения равнонадёжны.

## Влияние на землю Атаянс

| источник | v2 | v3 | Δ |
|---|---|---|---|
| ground_truth (≤1 см) | 160 | **196** | +36 |
| ground_truth_0.1 | 28 | **42** | +14 |
| всего в земле | 184 | **238** | +54 |

Систематика источника на каноне (dH = поверхность − отметка):
v2 ground_truth +0.54/0.99 (n=160) → v3 +0.56/0.98 (n=196) — медиана и MAD
не сместились: разрешённые конфликты не внесли перекоса.

**Неразрешённые 43** (все три чтения разные) остаются вне земли с полной
историей (`results/atayanc_pool_v3/atayanc_marks_pool_v3.csv`, колонка
`h_vlm`, лог `a2_third_read_log.csv`). Форсировать значение по «ближнему к
среднему» запрещено — это была бы выдумка.
