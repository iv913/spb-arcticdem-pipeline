## ГЛАВНОЕ: расщепление гранит/покрытие (вопрос METHOD_temporal_epochs §6)

Отметки Атаянс (≤ 1990) против fusion A2, разделение по принадлежности к
стенке (≤ 30 м от barrier=wall/quay):

| подмножество | n | median dH (fusion − отметка) |
|---|---|---|
| подтверждённые НА гранитных стенках | 82 | **−0.01 м** |
| подтверждённые ВНЕ стенок (покрытие) | 106 | **+1.09 м** |
| все чтения на стенках / вне | 253 / 358 | +0.23 / +1.41 |

Выводы:
1. **«Центровое смещение +0.5…+1.0» — это покрытие, а не рельеф и не датум.**
   На стабильных объектах (гранит набережных, ~36 лет без изменений) модель
   совпадает с планом до сантиметров. Перекладка покрытия за ~35 лет при
   r ≈ 0.03 м/год даёт наблюдаемые +1.1 м — предсказание METHOD_temporal_epochs
   §6 подтверждено измерением.
2. **Гребни набережных в поверхности верны** → пороги перелива для модели
   затопления можно брать из текущей поверхности + каталог гребней; это
   закрывает «набережная топится на +1 м» физически (REVIEW, этап 1).
3. Для 6.61: на граните D_implied ≈ −0.01 → D_true ≈ 0 усиливается.
4. Отметки покрытия при валидации — только с временнЫм членом σ
   (r ≈ 0.03 м/год — стартовая оценка; откалибровать по парам стрипов
   2013–2024, как в METHOD §5).
