## Что считает accept.py

- **земля и ICESat раздельно**; для ICESat — `n_eff` = число RGT и размах
  медиан по трекам (min/p25/p75/max); вердикты только по трекам (§1.2);
- разрезы: по источникам, по районам, по полосе высот 0–5 м;
- тиры conf 10 excl / 11 rest / 12 ok / 13 gold — глобально и внутри
  каждого источника, с разрезом near/not-near якорей;
- **у каждого фильтра отчёт до/после** (пул как подан → попадание в растр
  → пометка «в 15 м от якоря»);
- парный тест «новое против базы» — `stats_toolkit.paired_verdict`
  (земля по точкам, ICESat по трекам), если задан `--base`;
- `--scale 0.01` — конвенция Int16-сантиметров fusion 6.x.

## Памятка вызова (агенту A)

```bash
python3 scripts/validation/accept.py NEW_SURFACE.tif --scale 0.01 \
    --conf NEW_CONF.tif --pool results/validation_pool_v2/validation_pool_v9.csv \
    --base /tmp/my-project/download/mosaic_6.00/spb_terra_fusion_6.00_A2.tif \
    --base-scale 0.01 --out results/validation/accept_<stage>.json
```

Парный вердикт «новое против базы» печатается в `paired_vs_base`:
для земли — знаковый/Уилкоксон/бутстрап по точкам, для ICESat — по трекам;
порог практической значимости 0.1 м — поле `practically_significant`.
