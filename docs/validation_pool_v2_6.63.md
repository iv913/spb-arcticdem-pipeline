## Чтение

1. **Честный независимый контроль по земле — эти ~780 взвешенных отметок**, а не
   1765 смешанных с ICESat (аудит: 85 % пула v8 — ICESat; MAD такого пула не
   говорит о рельефе там, где топит).
2. **География ошибки:** открытые/измеренные места −0.35…+0.04; центр
   (prior-30 м) +0.54…+1.40. Картина совпадает с REVIEW (R1) и с 6.61:
   смещение поверхности, не датум.
3. **Оговорка времени (METHOD_temporal_epochs §6):** отметки Атаянс ≤ 1990 г.,
   поверхность на 2026; из +0.54 часть может быть перекладкой покрытия
   (r ≈ 0.01 м/год × ~35 лет ≈ 0.35 м). Разделить: отметки на граните
   (стабильные) против покрытия — сделать в 6.64 после привязки отметок к
   линиям гребней/набережных.
4. Протокол на будущее: любые новые источники проходят через этот пул;
   ICESat — отдельно, leave-tracks-out по RGT (n_eff = 12).

## Ограничения

- Паспорт: дата нивелирования марок не установлена (найти по паспорту марки).
- Купчино: геопривязка листа по адресу; VLM-чтение вслепую к dH не
  гарантировано для старых прогонов (аудит 2.2) — при сомнении брать
  до-фильтровую версию отчёта.
- Атаянс single reads (423 шт, вес 0.3) — кандидат на второе чтение
  (машинное, тем же методом, риск совпадения ошибки).
