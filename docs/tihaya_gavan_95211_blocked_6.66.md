- В ветке источник был обработан: 96 отметок, до VLM-фильтра MAD 0.534 /
  |dH|>1 м 20.8 % (§2.2 той же записки) — числа из пулов v5–v8.
- Термины приёмки B1: честный пул 5.67 = 322 = 226 (archi 514913 +

## Почему не воспроизведено

- `archi.ru` из среды исполнения недоступен: `curl` → 403 (без UA) /
  соединение обрывается (000); через WebFetch страница 95211 открывается,
  но HTML не конвертируется (ошибка извлечения), URL изображений не
  отдаются. Галерея проекта не листается, план с высотными отметками
  недоступен.
- Геопривязка и чтение отметок листа (трубка Атаянс 6.30–6.50: GCP по
  зданиям OSM + OCR) требуют самого растра; без него любые «96 отметок»
  были бы выдумкой.

## Что нужно (для пользователя)

1. Сохранённая страница проекта 95211 (HTML + изображения) или архив
   ветки `audit-remediations-A-I` (в ней уже есть разбор листа и, вероятно,
