непроверенные систематики: ошибка EGM2008 ~10 км; экстраполяция уровня
футштока на 2018–2026; смещение ATL06 над водой; поднятие суши в Балтии).

Способ 2 воспроизводится из handoff-скрипта: ATL06-SR (SlideRule) над открытой
водой западнее Котлина, один пролёт = одна выборка уровня (медиана, n ≥ 30
сегментов, MAD < 0.15 — отбор по качеству сегмента, НЕ по высоте §1);
среднее h − N = +0.140 ± 0.043 минус средний уровень БС-77 за 2018–2026
(+0.13 ± 0.04) = +0.01 ± 0.07.
