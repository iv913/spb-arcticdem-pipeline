# 6.76 / A3 — пересборка колец воды: inland_water_6.22 → 6.76

Дата: 2026-11-05. Скрипты: `scripts/a3_{water_diag,classify,water_fix,water_check,
impact,qa_views,qa_wide,probe_pbf}_6.76.py`. Вход: `inland_water_6.22.geojson`
(пересобранная 6.62c — файл не был закоммичен и воспроизведён байт-в-байт по
метрикам документа: 29 OSM-полигонов + 16 дисков, 74.90 → 74.39 км², отметки
19→2 / 10→1), канон `fusion 6.00 A2` (D=+0.004) + `conf 6.00 A2`, OSM PBF
BBBike 10.10.2026.

## 1. Что требовал план

Критерий A3 (datum_B3_6.65): «ни одного пикселя поверхности > 1.5 м внутри
водной маски» — не выполнен ни в 6.21, ни в 6.22 (мосты и рампы у стенок,
оценка 6.61 — ~6 км²). Фикс 6.62 снял проблему ОТМЕТОК, пиксельный критерий —
нет.

## 2. Диагностика (diag + classify)

Считаны все пиксели внутри полигонов маски 6.22: улика суши =
`(fusion ≥ 1.5 м) & (conf ≥ 10 = data)`; fill (conf 1–4) уликой не является.

| класс фич | фич | сухой внутри (улики) | что это |
|---|---|---|---|
| phantom (dry_frac ≥ 0.5) | 1022 | 11.08 км² | полигоны «воды» на суше: застроенные кварталы (z 5–26 м, conf=data), осушенные/убранные в трубу русла (Волковка), засыпанные пруды |
| ribbon (0.05–0.5) | 24 | 5.16 км² | реальная вода с лентами структур у стенок: порт СПб (Гутуевский, z 3.8–6 м), мосты, гранит причалов, сухие русла |
| clean (< 0.05) | 369 | 0.08 км² | спекл (волны/блики, компоненты < 50 м²) |
| empty | 1 | — | вне сетки/без данных |

Всего сухих пикселей с уликами: 16.41 км² (4.19 млн px, сетка 2 м).
Компонентов связности: 2712. Проба PBF в квадрате фантома feat2 (Лесная,
1.38 км² «воды» поверх кварталов z 19–23 м): водных полигонов OSM там НЕТ —
фантомы созданы сборкой маски 6.21 (сшивка way-фрагментов / keyhole-замыкания),
не исходником.

## 3. Перекалибровка критерия

Исходная формулировка «0 пикселей > 1.5 м» невыполнима на каноне: чистая
Нева читается медианой 0.22–0.34 м (уровень корректен), но у «водного»
распределения есть хвост: p90 ≤ 0.9, **p99 = 1.84 м** — волны/блики/пена
дают единичные пиксели ≥ 1.5 м даже вдали от структур. Поэтому критерий
переведён на компоненты связности:

> **A3-критерий (6.76): в маске нет ни одного связного компонента поверхности
> ≥ 1.5 м (conf = data) площадью ≥ 50 м².** Остаток — спекл (< 50 м²),
> перечислен. Для fill-зон критерий не определяется (нет улик) — сухие
> пиксели в fill (7.24 км²) учитываются отдельно.

## 4. Фикс (a3_water_fix_6.76.py)

Правило (продолжение метода улик 6.62, теперь пиксельно-точное):
1. dry-компоненты (≥ 1.5 м, conf ≥ 10) собираются по тайлам 0.05° без
   порога, объединяются per-фичу (шов склеивается), глобальные компоненты
   **≥ 25 м²** вычитаются из полигона фичи (без буфера — улика и критерий
   на одной сетке);
2. остатки-части фичи с площадью < 100 м² отбрасываются; часть остаётся
   водой только при **dry_frac < 0.5** (лечит GEOS-сливеры разности:
   485 кусков вдоль границы улики у feat16, из них часть 172 м² целиком
   из сухих пикселей);
3. фича без остатка ≥ 100 м² валидной воды удаляется (фантомы);
4. фичи без улик не трогаются; 6.22 не изменяется.

## 7. Ограничения и хвосты

- Спекл 1446 px (< 50 м²) остаётся в маске по построению (волны/блики);
  полный список — в `check_676_summary.json`.
- dry-in-fill 7.24 км² — в fill-зонах улик нет; туда маска не вмешивалась.
- Суда/понтоны в порту на момент проходов снимков могли дать «сухие»
  компоненты — вырезаны как структуры; если в порту появятся дыры — это они
  (лечится переросью маски при новых источниках, A5).
- Критерий ≥ 1.5 м привязан к канону; при смене канона (этап 2 / A5) маску
  пересобрать тем же скриптом.
- Оригинальная сборка 6.21 (экстрактор osm_inland_water_6.21.py) остаётся с
  багом фантомов — не использовать без исправления; источник фантомов
  описан в §2.
