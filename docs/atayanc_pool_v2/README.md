# Пул отметок «Атаянс-2013», v2 — двойное чтение

**Источник:** исходный лист `https://tehne.com/assets/i/upload/event/atayanc-2013-01.jpg`
(3000×2121, тот же, что у агента в 6.30). Лист прочитан целиком заново, вслепую
к каталогу 6.50 и к поверхности: 81 окно ~340×255 px с увеличением ×3.2, у каждой
отметки — координаты точки на листе и уверенность чтения H / M / L.

**Координаты:** основной лист — аффинная привязка агента `georef_6.30.json`
(проверена по зданиям OSM: медиана ошибки положения ~1.5 м); СЗ-фрагмент —
аффинная по 17 отметкам агента в этом фрагменте (невязка 0.03 м). У отметок
каталога — координаты каталога; у новых — по моей оценке положения точки
(±5 px ≈ ±4 м).

## Состав (709 точек)

| статус | n | что значит | `use` |
|---|---|---|---|
| `confirmed` | 160 | два независимых чтения совпали до 0.01 м | `ground_truth` |
| `near` | 28 | расходятся ≤ 0.10 м | `ground_truth_0.1` |
| `conflict` | 94 | чтения расходятся > 0.10 м (16 — первая цифра, 51 — вторая) | `third_read` |
| `new_single_read` | 377 | есть у меня, нет в каталоге агента | `candidate_second_read` |
| `agent_only` | 50 | есть в каталоге, я не нашёл / не прочитал | `candidate_second_read` |

Было: 332 отметки, H-уверенность у 6. Стало: **188 подтверждённых двумя
чтениями** + 427 кандидатов на второе чтение + 94 на третье.

`flag_vs_neighbours = 1` — высота отличается больше чем на 1 м от медианы
соседей в 60 м (16 точек, из них 9 — `agent_only`); проверить вручную.

## Что это меняет в оценке поверхности 6.00

| набор | n | dH = поверхность − отметка | \|dH\| > 1 м |
|---|---|---|---|
| весь каталог агента (одно чтение) | 330 | +1.00 | 60 % |
| **подтверждённые двумя чтениями** | 160 | **+0.54** (MAD 0.99) | 48 % |
| подтверждённые + ≤ 0.10 м | 188 | +0.64 | 52 % |
| `agent_only` (одно чтение агента) | 48 | +1.52 | 83 % |

Примерно половина «метрового» расхождения — ошибки чтения. На подтверждённых
отметках поверхность выше плана на ~0.5 м при большом разбросе. Это всё ещё
существенно и направлено туда же, что и тир gold по паспорту.

## Ограничения

- Два чтения могут совпасть в одной и той же ошибке (обе — машинные, по
  одному листу). Подтверждение снижает, но не исключает риск.
- Отметки плана 2013 г. — состояние на дату съёмки; у набережных и в местах
  благоустройства после 2013 возможны изменения.
- Отметки уреза воды (дроби «0.15 / 12.VI») и номера/даты под чертой не читались.

## Файлы

- `atayanc_marks_pool_v2.csv` / `.geojson` — пул с координатами, обоими чтениями,
  статусом, поверхностью 6.00, dH и флагом соседей;
- `claude_raw_reads_original_sheet.csv` — сырые чтения: окно, значение, x/y на
  листе, уверенность;
- `build_pool.py` — сборка пула из сырых чтений и каталога 6.50.
