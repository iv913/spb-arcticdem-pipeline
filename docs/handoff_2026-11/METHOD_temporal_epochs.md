# Методика: разные даты источников → одна поверхность на дату

Обязательна для обоих агентов. Дополняет `AGENT_HANDOFF_2026-11.md` (задачи B6, A8).

**Суть.** Каждый источник показывает землю на свою дату, и это часто не дата
публикации. Поверхность для затопления описывает землю **на одну заявленную
дату `T_ref`**. Поэтому у каждого наблюдения должна быть своя эффективная дата,
изменения рельефа между датами определяются по данным, а старое наблюдение
там, где рельеф с тех пор изменился, в результат не идёт.

## 2. Принципы

1. **Дата `T_ref` объявляется** в продукте (предлагаю 2026-01-01) и не меняется
   внутри прогона.
2. **У каждого наблюдения — эффективная дата `t_obs` и её неопределённость
   `σ_t`**, установленные по уликам, а не по дате публикации.
3. **Изменение рельефа — по данным, а не по прямоугольнику.** Ни одной области
   «намыв» или «стройка», заданной bbox; только карта изменений из §4.
4. **В ячейке с изменением используются только наблюдения после последнего
   изменения.** Старые не усредняются со свежими.
5. **Возраст — это ошибка.** К σ каждого наблюдения добавляется временной
   член (§5); старые данные в стабильных местах остаются, но с меньшим весом.
6. **Нет свежих данных после изменения — честная дыра.** Ячейка помечается
   «устарело», а не заполняется старым значением молча.
7. **Валидация учитывает дату отметки.** Отметку 1985 года нельзя сравнивать с
   поверхностью 2026 года без поправки на то, что изменилось между ними.

## 3. Реестр эпох источников (задача B6)

Файл `docs/source_epochs.csv` — по строке на источник или подсписок:
`source, t_obs (дата или интервал), sigma_t, how_dated, kind_of_height, notes`.

| источник | `t_obs` | как датировано | что за высота |
|---|---|---|---|
| ArcticDEM стрип | дата стрипа | `datetime` в инвентаре 5.74 | DSM (поверхность), 2 м |
| ArcticDEM мозаика | интервал `mindate…maxdate` на пиксель | бэнды мозаики | DSM, смесь эпох |
| ICESat-2 ATL06 / ATL03 | дата точки | `date`, `time_ns` | ATL06 — 40-м сегмент; ATL03 — фотон |
| GLO-30 / FABDEM | 2011–2015 | документация TanDEM-X | DSM / «голая земля» 30 м |
| паспорт (стенные марки) | дата нивелирования марки | **найти** (паспорт марки, каталог) | марка на стене здания |
| план Атаянс | ≤ 1990 (топооснова), 2013 — проектные здания | надписи на листе (ГДР, ЛГУ) | отметки земли (тротуар, проезд, набережная) |
| archi.ru, проектные листы | дата съёмки подосновы ≠ дате проекта | штамп, год съёмки | **существующие или проектные** — различать |
| DXF-съёмки | дата съёмки | штамп / свойства файла | топосъёмка |
| OSM | дата выгрузки | имя файла | не высота: геометрия, `building`, `landuse=construction` |
| оптика Esri / Sentinel-2 | дата снимка | identify-API / метаданные сцены | не высота: улика изменения |

Правила:
- дата публикации **не** заменяет дату съёмки; нет улик — `σ_t` широкая (интервал
  «от … до …»);
- на проектных листах отличать **существующие** отметки от **проектных** (в
  российской традиции существующие — чёрные, проектные — красные или в рамке);
  проектные — это не земля, а план на будущее; в «землю» не идут;
- для каждого источника — тип высоты: стенная марка, отметка покрытия, гребень
  стенки, DSM, ATL. Это определяет, как высота стареет (§5).

## 4. Карта изменений (задача A8)

На сетке 8–10 м строится временной ряд каждой ячейки из **датированных высотных**
наблюдений: стрипы 2 м (после корегистрации по стабильным участкам), фотоны
земли ATL03, датированные отметки. ATL06 в застройке в ряд не входит.

**Детектор ступени** (как `lib_strips.detect_surface_change`): дата `t*` —
изменение, если все наблюдения после `t*` выше (или ниже) всех до `t*` больше
чем на порог (0.5 м; для 2 м стека — по его собственному шуму), и с каждой
стороны ≥ 2 наблюдения. Сезонные эффекты (снег, листва) — не изменения: зимние
стрипы и leaf-on ATL — с сезонным флагом и в детекторе не участвуют.

**Улики без высоты** (не создают изменение, но подтверждают или датируют его):
появление здания в OSM, `landuse=construction`, изменение яркости или класса на
оптике между датами.

**Классы изменений** и что с ними делать:

| класс | признак | как стареет | в продукте |
|---|---|---|---|
| намыв / подсыпка | рост > 1 м на открытой территории | после намыва — осадка (дм/год первые годы) | только наблюдения после `t*`; σ с членом осадки |
| новая застройка | здание в OSM / на оптике, рост DSM | земля вокруг — новая планировка | здания — препятствия (полигоны OSM); земля — только после `t*` |
| стройплощадка сейчас | `construction` в OSM, яма или навалы на оптике | непредсказуемо | «устарело / нестабильно»; в затоплении — отдельный класс |
| реконструкция дороги / набережной | ступень 0.1–0.5 м по линии | — | только после `t*` |
| перекладка покрытия | медленный рост 0.05–0.3 м за десятилетия | ~1 см/год (оценить) | временной член σ |
| снос / котлован | падение | — | только после `t*` |
| стабильно | ступени нет | — | все наблюдения, с весом по возрасту |

**Приёмка карты изменений** — на известных событиях с подтверждённой датой:
очередь намыва «Морского фасада», застройка Лахты, реконструкция набережных
(даты — из открытых источников, записать в `docs/change_events.csv`). Доля
найденных и ложных — в отчёте.

## 5. Как собирать поверхность на `T_ref`

Для каждой ячейки:

1. Взять наблюдения после последнего изменения `t*` (или все, если изменений нет).
2. Полная σ наблюдения:
   `σ² = σ_изм² + σ_датум² + (r · (T_ref − t_obs))² + (r · σ_t)²`,
   где `r` — скорость изменения для класса ячейки и типа высоты:
   - стенная марка, гранитный парапет набережной: `r ≈ 0` (+ осадка здания, если известна);
   - отметка покрытия в старом центре: `r` ~ 0.01 м/год — **стартовое
     допущение**, калибровать по парам стрипов 2013–2024 в стабильных местах
     и по отметкам с известной датой;
   - намыв в первые годы после подсыпки: по ряду ICESat / стрипов на нём же;
   - стройплощадка: `r = ∞` (наблюдение не используется).
3. Взвешенное решение (screened Пуассон из этапа 2 REVIEW) с весами 1/σ².
4. В продукт — каналы: `t_obs_eff` (эффективная дата значения в пикселе),
   `stale` (после последнего изменения данных нет), `change_class`, полная σ.

**Где сейчас точно нужна эта логика:**
- **намыв ВО и Лахта:** мозаика (≤ 2021) там устарела; брать стрипы ≥ 2022,
  фотоны ATL03 2024–2026; здания — полигоны OSM 2026 как препятствия;
  участки, застроенные после мая 2024 (последний стрип), — `stale`;
- **prior 30 м** (2011–2015) — только как слабый фон и нигде, где есть изменение
  после 2015;
- **старый центр:** рельеф стабилен, но покрытие перекладывали; отметки плана
  (≤ 1990) — с временным членом σ.

## 6. Валидация с учётом дат

- **Сравнивать отметку с поверхностью на её эпоху** там, где есть стрип той же
  поры, или **только в стабильных ячейках** (класс «стабильно» в §4).
- В отчёте `accept.py` — **dH против возраста отметки** (`T_ref − t_obs`) по типам
  высоты. В стабильных местах наклон должен совпадать с `r` покрытия; если
  dH растёт с возрастом заметно сильнее — неверна эпоха или есть систематика.
- **Проверка на плане Атаянс** (топооснова ≤ 1990): на 160 подтверждённых
  отметках поверхность выше на +0.54 м. Часть этого может быть перекладкой
  покрытия за ~35 лет. Проверить: отметки на гранитных стенках и парапетах
  (стабильные) против отметок покрытия проездов и тротуаров (перекладываемые).
  Если у покрытия dH заметно больше — это время, а не ошибка модели.
- Стенные марки паспорта стареют медленнее отметок покрытия: держать их
  отдельной строкой отчёта.
- Запрещено: сравнивать с поверхностью отметки из ячеек с изменением после
  даты отметки, если поверхность — на `T_ref`.

---

## 7. Затопление с учётом дат

- Карта на `T_ref`; в легенде — дата и доля площади `stale` в полосе 0–5 м по районам.
- Пиксели `stale` и стройплощадки — отдельный слой «нет актуальных данных»,
  а не залито или сухо по старому рельефу.
- Здания, построенные после даты высотных данных, — препятствия из OSM на
  `T_ref`; земля вокруг них — `stale`, пока нет свежего наблюдения.

---

## 8. Чек-лист приёмки

- [ ] у каждого наблюдения в пуле и в опоре есть `t_obs`, `σ_t`, `how_dated`;
- [ ] в коде нет областей «намыв» / «стройка», заданных bbox;
- [ ] карта изменений проверена на ≥ 5 известных событиях с датой;
- [ ] в ячейках с изменением после `t*` нет наблюдений старше `t*`;
- [ ] `r` откалиброван по данным, а не взят из этой методики;
- [ ] в продукте есть каналы `t_obs_eff`, `stale`, `change_class`;
- [ ] в отчёте `accept.py` — dH против возраста отметки по типам высоты;
- [ ] доля `stale` в полосе 0–5 м — в легенде карты затопления.

## 9. Спутниковые снимки: роль и правила

**Снимок — улика, а не высота.** По одному снимку высоту не получить; по стерео
со сверхвысоким разрешением — получить можно, но это DSM, и это коммерческие данные.

**Где снимки нужны:**

| задача | что даёт снимок | какое разрешение достаточно |
|---|---|---|
| карта изменений (A8) | датирует намыв, застройку, снос; стройплощадки сейчас | 10 м (Sentinel-2) — датировка; ≤ 1 м — что именно построено |
| слой `stale` | участки, изменившиеся после последнего стрипа (19.05.2024) | 10 м |
| водная маска (A3) | где вода, где суша (Заячий остров, Стрелка) | ≤ 1 м |
| чтение отметок (A2) | отметка «внутри здания» — это двор или ошибка | ≤ 0.5 м |
| каталог гребней (A4) | линия парапета набережной, дамбы, насыпи; мосты и трубы как связи | ≤ 0.5 м |
| ICESat / стрипы | кроны, крыши, снег, вода под точкой (фильтр по свойствам места, не по dH) | ≤ 1 м + сезон снимка |

**Источники:**
- **Sentinel-2** (10 м, каждые несколько дней с 2015 г., дата у каждой сцены,
  открытая лицензия) — основной для датировки изменений; доступ из среды агента
  уже был (Earth Search, этап 5.87).
- **Landsat** (30 м, с 1980-х) — фазы намыва до 2015 г.
- **Esri World Imagery** (0.3–0.5 м, у СПб — съёмка 04.2025–04.2026) — для
  визуальной проверки. Мозаика из снимков разных дат: дату брать для каждого
  места через identify-API и хранить. Условия использования для производных
  слоёв в распространяемом продукте проверить до использования; для
  публикуемых слоёв опираться на Sentinel-2 / Landsat или на лицензированные снимки.
- **Сверхвысокое разрешение и стерео** (Pleiades Neo, WorldView и т. п.) —
  коммерческие; стерео 0.3–0.5 м даёт DSM, который видит улицы между домами
  лучше ArcticDEM. Решение о покупке — за пользователем.

**Правила:**
1. У каждого снимка — дата съёмки в метаданных результата; снимок без даты
   уликой не является.
2. Сезон снимка учитывается: снег и листва — не изменение.
3. Если снимки разбирает VLM, то вслепую: в запрос не попадают ни dH, ни высота
   модели, ни значение отметки; разбор ко всем точкам набора, а не к «плохим».
4. Изменение по снимку подтверждает или датирует ступень высоты, но не создаёт её;
   участок, изменившийся на снимке без свежих высотных данных, получает `stale`.
