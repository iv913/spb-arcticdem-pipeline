## 1. Общие правила (обоим)

**Валидация — запрещено:**
1. фильтровать контрольные точки по |dH| от модели или по согласию с ней — ни
   порогом, ни триажем, ни VLM, который видит dH или модельную высоту;
2. делить точки ICESat случайно по точкам — только треками (RGT) целиком;
3. проверять на отметках, которые вошли в якоря, поправку или калибровку;
4. выбирать метод или параметр по виду карты затопления;
5. сравнивать метрики на разных выборках;
6. выносить вердикт по точечному MAD — только парные тесты из
   `scripts/stats_toolkit/` (знаковый, Уилкоксон, bootstrap CI, порог 0.1 м).

**Валидация — обязательно:**
- критерии приёмки записаны в коммит **до** прогона;
- наземные отметки и ICESat — в отчёте раздельно, ICESat — по трекам (n_eff = число RGT);
- разбивка по районам, тирам и полосе высот 0–5 м;
- у каждого фильтра — отчёт до и после.

**Датум:** одно преобразование на весь проект —
`H_bs77 = h_ell − N_EGM2008(lon, lat) − D` (`geoid_egm2008.py`). Константы
15.673 / 15.9 / 16.04 / 16.472 в новом коде запрещены.

**Секреты:** `.env` удалить из индекса (`git rm --cached .env`, добавить в
`.gitignore`). Токены в коммиты, логи и файлы `upload/` не попадают.

*Приёмка:* самотест `geoid_egm2008.py` (N 15.76–16.00 м по городу); старые

**B3. Сдвиг датума D.** Подобрать `D` функцией `fit_datum_offset` по ≥ 20 точкам с
известными одновременно эллипсоидальной высотой и высотой БС-77 (пункты ГГС с

залива у Кронштадта по ICESat-2 ATL13 против уровня на футштоке на те же даты —
только при наличии ряда уровней.
*Приёмка:* `D`, его SE, n и список точек — в `results/datum_D.json`.

**B4. Валидационный пул v9.** Две независимые части:
- **земля** — наземные отметки вне любых якорей и поправок (archi 514913, «Тихая
  гавань», паспортные holdout, новые листы), **без** VLM-фильтра;
- **ICESat** — по трекам; VLM (если нужен) применяется ко всем точкам, вслепую:
  в запрос не попадают ни dH, ни высота модели; в отчёте обе версии.
Атаянс входит в «землю» из `atayanc_pool_v2/`: сразу — только `use =
ground_truth` и `ground_truth_0.1` (188 отметок, два независимых чтения);
остальные — после второго / третьего чтения агентом A (A2). Точки с
`flag_vs_neighbours = 1` — после ручной проверки.
*Приёмка:* `docs/validation_pool_v9.md` с составом по источникам и районам;
повторный запуск с другим порядком точек даёт тот же VLM-результат ± 2 %.

**B5. Протокол приёмки как код.** `scripts/validation/accept.py`:
на вход растр + пул v9, на выход JSON с метриками по §1 (земля / ICESat по

*Приёмка:* ни одной наземной отметки и ни одного пикселя поверхности > 1.5 м
внутри водной маски; Заячий остров, Стрелка, Дворцовая — суша.

**A4. Каталог гребней (этап 1 REVIEW).** Геометрия из OSM
