## 2. Главная находка: противоречие датума разрешено — N_geo циркулярна

### Тождество

```
N_geo   = median(h_ATL08_ell − h_DSM_BS)          (38_atl08_anchors.py:63)
h_DSM_BS = h_ArcticDEM_ell − SHIFT_M,  SHIFT_M = 15.673   (spb_full_run_v2.py:56)
⇒ N_geo ≡ 15.673 + median(h_ATL08_ell − h_ArcticDEM_ell)
         = 15.673 + 0.799 = 16.472
```

Эти 0.799 м — **разность поверхностей** (наземный фит ATL08 против DSM
ArcticDEM), а не геоид. Вычитая её из лазера, вы возвращаете в якорь
собственный уровень DEM:

```
h_anchor_bs = h_ATL08 − N_geo ≈ (уровень DSM) + (форма лазера)
```

**Якорь привязан к тому, что он должен был исправить.** Лазер приносит
только относительную форму, абсолютного уровня — ноль.

Это объясняет сразу три наблюдения, которые иначе выглядят несвязанными:
глобальный MAD не сдвинулся; выигрыш есть только у самих штампов;
нулевая чувствительность RMSE к ±0.5 м.

### Два симптома, подтверждающие это изнутри ваших же файлов

- Разброс остатка N_geo: `median_abs_resid` = 1.18 м, `p90` = 7.818 м,
  `frac_within_1m` = 0.447. Для константы датума, которая по городу
  обязана держаться ±0.1 м, это не разброс геоида — это разброс
  поверхности.
- `caveat` в самом `atl08_anchors_v1.meta.json`: «медиана слегка завышена
  асимметрией хвоста». Завышена не слегка и не хвостом — завышена
  систематикой DSM на 0.80 м.

### Независимая оценка по паспорту — и она не совпадает

Класс 21 — пиксели, где DSM принят напрямую (минимум обработки), и отбор
их шёл по огибающей, а не по согласию с паспортом, то есть к `hp`
нециркулярно:

| маршрут | n | median(модель − марка) | ⇒ константа эллипсоид→БС |
|---|---|---|---|
| **detail 21** | 62 | −0.034 м, 95 % CI [−0.279, +0.278] | **15.707**, CI **[15.43, 15.99]** |
| detail 23 | 138 | −0.613 м, CI [−1.155, +0.098] | 16.286 |
| ATL08 против DEM | 9 338 | — | 16.472 |

**16.472 лежит вне CI паспортного маршрута.** Заодно задним числом
объясняется старое «16.11–16.30 по трём независимым маршрутам»: класс 23
даёт 16.286, потому что он заполнен prior'ом и занижен — все три маршрута
шли через одну и ту же заниженную поверхность и независимыми никогда
не были.

### Что делать

1. Взять N из **независимой модели геоида** (сетка EGM2008), не из
   сравнения с DEM. Либо принять 15.71 по реперам.
2. Переоценить якоря на новой N и **перезапустить C1–C2**. Тогда 0.80 м
   становится измеримым смещением «DSM против лазера», которое можно
   корректировать, а не константой датума, в которой оно спрятано.
3. Это единственная из обозримых правок, способная заметно сдвинуть
   класс 23 (65–69 % площади), потому что только она даёт якорям
   абсолютный уровень.

**Честная оговорка.** Конкурирующее объяснение: наземный фит ATL08 в
плотной застройке смещён вверх на ~0.8 м, и тогда N_geo завышена
смещением лазера, а не DSM. Отсюда я не различу эти версии без
независимого геоида. Но вывод в обоих случаях один: **N_geo — не датум
и не должна выводиться из сравнения с DEM.**

## 3. Заголовочный выигрыш C1–C2 не проходит парные тесты

Заявлено: MAD 1.552 → 1.422 (−8.4 %). Пересчёт на тех же 202 парах:

| тест | результат |
|---|---|
| MAD (сырой) | 1.046 → 0.959 |
| median\|dH\| | 0.978 → 0.966 (**+0.013 м**) |
| **парный знаковый тест** | лучше 96 / хуже 87 / ничья 19, **p = 0.55** |
| **Уилкоксон** | **p = 0.154** |
| **bootstrap 95 % CI на выигрыш** | **[−0.053, +0.144] м** — нуль внутри |

Вердикт должен быть **НЕРАЗЛИЧИМО**, а не −8.4 %. Это четвёртый случай
той же ловушки малой мощности. В README есть запрет «не сравнивать
метрики на разных выборках», но нет правила «не выносить вердикт по
точечному MAD».

### Но эффект есть — и он строго локальный

| расстояние до якоря | n | median\|dH\| | выигрыш | знаковый тест |
|---|---|---|---|---|
| **0–50 м** | 15 | 1.282 → 0.824 | **+0.458 м** | 8/15, p = 1 |
| 50–200 м | 50 | 0.831 → 0.820 | +0.011 | 22/46, p = 0.88 |
| 200–500 м | 57 | 1.032 → 1.012 | +0.020 | 30/50, p = 0.20 |
| > 500 м | 80 | 0.968 → 0.968 | +0.000 | 36/72, p = 1 |

Spearman(выигрыш, расстояние) ρ = −0.085 (знак верный, p = 0.23 —
размазан, потому что 185 из 202 марок сидят в зоне нулевого выигрыша).

Внутри 50 м метод даёт **0.46 м** — это много. Дальше 50 м не даёт
ничего. В 200 м от якоря лежат 65 из 202 марок, медиана 346 м,
p90 1253 м.

**Утверждение README «эффект структурный (через поле prior), а не за счёт
марок на якорях» данные опровергают: эффект целиком у штампов.**
И это не провал метода — это дефицит покрытия. Рычаг — **плотность
якорей**, а не алгоритм. 9 187 штампов на 972 км² ≈ 9.5/км² при 11 RGT.
Переход с 100-м сегментов ATL08 на фотоны ATL03 даёт шаг ~20 м и
поднимает плотность на порядки — это была работа `lib_icesat`.

соотношение ~10 держится во всех версиях (тяжёлые хвосты, не сдвиг).

**Зеркало 425.8 против 329 км² закрыто декларацией, а не измерением.**
Строка в таблице отвергнутых объясняет +29 % определением границ

Геометрия компонент на руках: обрезка по створу КЗС и отдельный подсчёт

**Пяти библиотек в репозитории нет**: `lib_strips`, `lib_icesat`,
