# atayanc_6.52 — ревизия поверхности участка (DSM v2 + барьер уреза)

Ревизия серии 6.52 (полный протокол: results/fusion_6.52/revision_protocol_6.52.md,
корень: download/spb_revision_protocol_6.52.md).

## Что изменилось против 6.50

1. **DSM v2** (atayanc_plot_dsm_1m_6.52.tif): ref-окно p25 только по суше
   (base ≥ 0.5 м), 2-проходная коррекция (локальная медиана k=24 → отбраковка
   55 выбросов → взвешенное среднее), sigma 60 м. Контроль по 332 отметкам:
   bias −0.24 / MAD 0.42 м (6.50: −0.15/0.46, всплесков больше нет).
2. **Затопление с барьером 12 м** от воды OSM (EDT): лента смешанных пикселей
   уреза (диагностика 6.51) убрана: +1 м 0.051→0.016 км², +3 м 0.880→0.654,
   +5 м 1.519→1.373. Оставшиеся точечные пятна на +1 м — хвост рампы 12–15 м
   и реальные низкие дворики.
3. Карта: atayanc_plot_map_6.52.html (план + DSM-хиллшейд + здания + 332
   отметки + затопление +1..+5 с барьером).

- atayanc_plot_map_6.52.html — карта (подложка Esri Dark Gray)
